## Inglés

**Data and code availability.** The versioned numerical data and accompanying source code are archived in Zenodo (Treny Ortega, 2026, https://doi.org/10.5281/zenodo.22863543). The repository is https://github.com/aleetreny/Shape-of-Science-Robustness. The archive preserves work identifiers, frozen vectors, exact selections and candidate sets, per-condition measurements, processing configurations and source snapshots. Its README provides checksum validation, reproduction of the main-figure summaries and independent checks from vectors under fixed conditions. These checks do not constitute a complete rerun of every analysis. Historical plaintext title/abstract input tables and model weights are excluded; non-text metadata and hashes identify the omitted inputs. Exact regeneration of the historical embeddings from text is therefore outside the tested public route. Original code is MIT; original documents and numerical results are CC BY 4.0; OpenAlex metadata retain CC0, with third-party rights unchanged.

## Español

**Disponibilidad de datos y código.** Los datos numéricos y el código de esta versión están archivados en Zenodo (Treny Ortega, 2026, https://doi.org/10.5281/zenodo.22863543). El repositorio es https://github.com/aleetreny/Shape-of-Science-Robustness. El archivo conserva identificadores de artículos, vectores congelados, selecciones y conjuntos de candidatos exactos, medidas por condición, configuraciones y copias de los programas. Su README explica cómo comprobar la integridad de los archivos, reproducir los resúmenes de las figuras principales y repetir comprobaciones independientes desde vectores en condiciones fijadas. Estas pruebas no equivalen a repetir todos los análisis. Se excluyen las tablas históricas con títulos/resúmenes usados como entrada y los pesos de los modelos; los metadatos sin esos textos y sus huellas identifican las entradas omitidas. Por tanto, la vía pública comprobada no incluye regenerar exactamente los vectores históricos desde el texto. El código propio usa MIT; los documentos y resultados numéricos propios, CC BY 4.0; los metadatos OpenAlex conservan CC0 y los derechos de terceros no se modifican.
